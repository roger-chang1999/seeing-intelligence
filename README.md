# 看見智慧：從人的直覺到神經網路
*Seeing Intelligence — From Human Intuition to the Multi-Layer Perceptron*

## 課程框架（不變的原則）
1. **起點**：從「人類如何觀察、理解智慧」出發，逐步推進到 MLP。
2. **每個觀念都要有程式 + 動畫**：用 code 產生視覺化動畫來表達，不靠公式說服人。
3. **受眾 (TA)**：40–50 歲的企業主，非 20 歲學生。
   - 內容要明確、好懂、貼近商業與生活經驗。
   - 公式只當配角；先有直覺與畫面，再有名詞。
4. **協作方式**：大綱與關鍵決策會透過 grill-me 互相質疑後才定案。

## 故事主線（草稿）
人的智慧 = 面對世界的 input 產生好的 output → input/output 的對應關係就是**函數** →
ML 的最大框架：「問題背後存在一個 f(x)，用統計的方式從資料把 f(x) 找出來」→

1. 智慧 = input → output = 函數 f(x)
2. 老師傅的經驗法則 = 統計；最簡單的 f：y = ax + b
3. Loss：猜得多爛
4. 梯度下降：一步一步變好
5. 世界不是直線：直線硬套失敗
6. 神經元 = 線性 + 一個彎折（activation）
7. MLP = 彎折疊起來，拼出任何 f
   - 過擬合／資料品質：加參數後自然出現
8. 從「預測數字」到「選答案」：分類與 softmax
9. 圖片也是 input：攤平像素丟 MLP → CIFAR-10 約 50%
10. 卷積：局部、共享的眼睛，逐層疊出特徵
11. VGG = CNN 負責看 + MLP 負責判斷
