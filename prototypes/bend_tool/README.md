# 彎折工具（第 5–7 步 + 過擬合）

一家店每個時段的來客數。學員用「直線 + 彎折（ReLU 神經元）」去貼合資料，
再按「進入實戰」揭曉沒看過的資料，親眼看到欠擬合 → 剛好 → 背答案。

**成品是單一 HTML 檔 [`docs/bend_tool.html`](../../docs/bend_tool.html)**：不需要伺服器、不需要安裝，
雙擊即可開啟，也可以直接放上 GitHub Pages。

| 檔案 | 內容 |
|---|---|
| `core.py` | Python 參考實作：資料（10 筆練習 + 40 筆實戰，固定 seed 5）、模型、訓練；也是 Kaggle 加碼的底稿 |
| `trainer.js` | `core.py` 訓練邏輯的 JS 移植（train / learn / sweep） |
| `bend_widget.js` | 畫面與互動：即時繪圖、滑桿、拖動彎折點、練習／實戰切換、成績單 |
| `template.html` | 頁面骨架與 CSS |
| `build.py` | 把以上組成 `docs/bend_tool.html` |

修改後重新產生：
```bash
python build.py      # 需要 numpy
```

## 驗證過的成績單（一鍵掃描，從預設起點訓練）
| 神經元數 | 0 | 1 | 2 | 3 | 4–12 |
|---|---|---|---|---|---|
| 練習誤差 | 26 | 23 | 23 | 10 | 0.4 |
| 實戰誤差 | 22 | 22 | 22 | 10 | 11.3 |

- 0–2：欠擬合，兩邊都爛
- 3：剛好，練習 ≈ 實戰
- 4 以上：背答案，練習近乎滿分、實戰沒有變好
- ReLU 過擬合時實戰誤差「不會明顯回升」，故事重點是「練習滿分 ≠ 實戰更好」

## 「讓機器自己學」的防卡住機制
從學員當下的狀態出發做梯度下降，60 次隨機情境中有 33 次卡在局部最小值
（例如 4 個神經元學完後拿掉一個再學）。所以 `learn` 會：
1. 重設折點跑到所有練習點右邊的「死神經元」
2. 同時從預設起點再學一次，取較好的那次；若採用後者，畫面提示「換了一個起點重新學」

修正後 60 次中 0 次卡住。這個現象本身也是「工程師加碼」的好題材：局部最小值。

## 試玩重點
1. 拖滑桿、拖橘色彎折點，看線即時跟著動
2. 加 3 個神經元按「讓機器自己學」→ 按「進入實戰」：練習 10、實戰 10
3. 加到 8 個再學一次：練習幾乎 0，實戰還是 11 —— 背答案
4. 講師用「一鍵掃描」讓整張成績單逐欄長出來；點任一欄可載入該模型
