# 彎折工具（第 5–7 步 + 過擬合）

一家店每個時段的來客數。學員用「直線 + 彎折（ReLU 神經元）」去貼合資料，
再按「進入實戰」揭曉沒看過的資料，親眼看到欠擬合 → 剛好 → 背答案。

| 檔案 | 內容 |
|---|---|
| `core.py` | 資料（10 筆練習 + 40 筆實戰，固定 seed 5）、模型、梯度下降、一鍵掃描 |
| `app_gradio_js.py` | Gradio 外殼、版面、CSS；把 `train`、`sweep` 開放給瀏覽器呼叫 |
| `bend_widget.js` | 瀏覽器端：即時繪圖、滑桿、拖動彎折點、練習／實戰切換、成績單 |

畫面在學員瀏覽器裡即時重畫；按「讓機器自己學」時才呼叫伺服器上的 Python 訓練。
（早期的純 Gradio 版本 A 因拖動時無法即時更新而淘汰，見 git 歷史。）

## 驗證過的成績單（一鍵掃描，從預設起點訓練）
| 神經元數 | 0 | 1 | 2 | 3 | 4 | 5–12 |
|---|---|---|---|---|---|---|
| 練習誤差 | 26 | 23 | 23 | 10 | 0 | 0–2 |
| 實戰誤差 | 22 | 22 | 22 | 10 | 11 | 11–12 |

- 0–2：欠擬合，兩邊都爛
- 3：剛好，練習 ≈ 實戰
- 4 以上：背答案，練習近乎滿分、實戰沒有變好
- ReLU 過擬合時實戰誤差「不會明顯回升」，故事重點是「練習滿分 ≠ 實戰更好」

## 在本機執行（Windows / macOS）
需要 Python 3.10 以上。在這個資料夾裡打開終端機：

```powershell
python -m venv .venv
.venv\Scripts\activate          # macOS / Linux：source .venv/bin/activate
pip install -r requirements.txt
python app_gradio_js.py          # 自動打開 http://127.0.0.1:7861
```

## 試玩重點
1. 拖滑桿、拖橘色彎折點，看線即時跟著動
2. 加 3 個神經元按「讓機器自己學」→ 按「進入實戰」：練習 10、實戰 10
3. 加到 8 個再學一次：練習幾乎 0，實戰還是 11 —— 背答案
4. 講師用「一鍵掃描」讓整張成績單逐欄長出來；點任一欄可載入該模型
